Promedio de la plataforma: {{ global().tasa | number: '1.2-2' }} %

Cómo lo calcula Spark
  1. join de bookings con offerings por offering_id para saber el proveedor de cada reserva.
  2. groupBy("provider_id") agrupa las reservas de cada proveedor.
  3. count cuenta todas y sum(status == "CANCELLED") las canceladas.
  4. La tasa se redondea a 2 decimales con F.round.
(bookings.join(offerings_clean, on="offering_id")
  .groupBy("provider_id")
  .agg(F.count("*").alias("reservas"),
       F.sum((F.col("status") == "CANCELLED")
             .cast("int")).alias("canceladas"))
  .withColumn("tasa_cancelacion",
       F.round(F.col("canceladas") / F.col("reservas") * 100, 2)))
}
